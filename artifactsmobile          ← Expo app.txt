If you want to make changes yourself:

Edit any file in the Replit file tree — changes are saved in the workspace immediately.
Most code changes in artifacts/mobile/app/... hot-reload automatically in the Expo dev server.
If you change package.json, app.json, or babel.config.js, restart the mobile workflow from the workflow panel.
If you want to push your own changes to GitHub, use the Git panel in Replit or run git push in the Shell.
